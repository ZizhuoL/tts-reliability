# Repository contents and publication policy

This Git repository is rooted in `tts-reliability/`. The parent workspace and
other projects are outside its scope. The initial remote is the private
`ZizhuoL/tts-reliability` repository. Changing visibility requires a separate
owner decision and another review of third-party materials and personal data.

## Tracked content

| Content | Reason |
| --- | --- |
| `src/`, research `scripts/`, and `tests/` | Inspectable implementation and correctness checks |
| `configs/`, requirements, and environment helper | Reproduction settings and dependency versions |
| `README.md`, `docs/`, and English project instructions | Project presentation, attribution, methods, and limitations |
| `STATUS.md` | Concise current status and recovery guidance |
| Selected result summaries, CSV tables, PNG/PDF plots | Evidence for reported outcomes and uncertainty |
| Final protocol and all nine final `raw.jsonl` files | Prespecified comparison and all 1,080 terminal attempt records |
| `results/repository-evidence/` | Path-redacted copies of selected historical metadata |

Selection is enforced by `.gitignore`: new top-level folders and generated
results are ignored unless allowed. Before every future upload, review
`git status --short` and `git diff --cached --stat`; do not force-add ignored
assets without reviewing their contents and publication purpose.

## Local-only content

- Downloaded data, pretrained models, trained checkpoints, and upstream checkouts.
- Python environments, caches, lock files, operating-system metadata, and credentials.
- All audio, including the personal reference recording and generated voice demos.
- Personal-voice scripts, demo results, and private reference transcripts.
- Full logs, duplicate plot inputs, exploratory snapshots not selected for review,
  and the original handoff journal in `notes/STATUS.history.zh.md`.
- Original metadata containing personal absolute filesystem paths; exported
  counterparts are described below.

These files remain on the original machine. Excluding them from Git does not
delete them or provide a backup for them. Some historical report paths identify
local-only artifacts. In particular, the complete listening bundles and their
WAV links are available locally, not from a fresh GitHub clone.

## Evidence integrity and language

Maintained documentation is English. Original machine-readable experiment
records are preserved as evidence, rather than rewritten to match a new style.
The hash-bound historical `scripts/prepare_listening_bundle.py` retains its
original Chinese listening-index strings: changing that file would invalidate
the frozen final-run source binding. This is an explicit archival exception,
not an untranslated project report. Personal demo generators are excluded.

Thirteen original JSON metadata files contained the original user's absolute
project directory. Their repository exports replace that directory with
`<repository>` and preserve every other byte of textual content.
`results/repository-evidence/EXPORT.json` identifies each original and exported
file, the SHA-256 of both, and the transformation. The originals remain local
and unmodified. Exported copies must not be substituted into a historical
resume or integrity check that expects the original hash.

The frozen protocol, final attempt records, configurations, model code, and
training code are not regenerated by this documentation cleanup. Checkpoint
identity, raw outcomes, and historical integrity receipts are not retroactively
changed to imply a new experiment.

## Reproduction boundaries

A clone is a source-and-evidence distribution, not a complete 16 GB workstation
snapshot. Follow [the local workflow](local_workflow.md) and
[reproduction notes](reproduction_notes.md) to obtain public dependencies and
prepare a new run. Exact historical continuation also requires the original
local checkpoints, data snapshots, path bindings, and source hashes. Do not
bypass those checks or reuse the historical output directory for a changed run.

The repository does not assign a blanket license to upstream code, recordings,
models, or course assets. Their original sources and terms remain separate;
see the README and research notes for attribution.
